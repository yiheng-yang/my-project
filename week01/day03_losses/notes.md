# Day 3 · 概率、MLE、Entropy、Cross Entropy

> Week 1 · Day 3 —— 今天回答一个问题：**分类的 loss 为什么是交叉熵？**

---

## 一、核心链条（记住这条就够了）

```
① 数据已经发生了                                 ← 起点
② 找一组参数，让"产生这批数据"的概率最大            ← 最大似然 MLE
③ 取 log（单调变换，最大值位置不变）-> 乘积变求和     ← log-likelihood
④ 加负号（最大化变最小化）                        ← NLL = loss
⑤ 代入分类任务 -> 交叉熵                          ← 你写的 losses.py
```

**关键假设：i.i.d.**（独立同分布）—— 没有它就不能把概率连乘起来。

**关键代入**：分类任务里，`P(xᵢ|θ)` = **模型给正确类别的预测概率**。

---

## 二、三个概念的关系

```
H(p)      = 真实分布自身的不确定性（常数，训练时不动）
CE(p, q)  = 用 q 去编码 p 的代价
KL(p‖q)   = CE(p,q) − H(p)  =  两个分布差多远

→ H(p) 是常数，所以「最小化 CE」和「最小化 KL」等价
→ 这就是为什么分类直接用 CE 就够了
```

---

## 三、不同假设 → 不同损失（这张表能解释很多"为什么"）

| 假设数据服从 | MLE 导出 |
|---|---|
| **类别分布**（分类）| **Cross Entropy** |
| **高斯分布**（回归）| **MSE** |
| **拉普拉斯分布** | **MAE** |

> 损失函数不是随便挑的，它是「你对数据的假设」的数学后果。

---

## 四、数值稳定：为什么要 max-shift

```
softmax(x)ᵢ = exp(xᵢ) / Σ exp(xⱼ)
```

直接算会溢出：`exp(1000) = inf` → `inf/inf = nan`

**解法**：先减最大值。因为 **softmax 对平移不变**：

```
softmax(x) == softmax(x − c)     对任意常数 c 成立
```

减掉之后最大的指数变成 `exp(0) = 1`，永远不会溢出。

**cross_entropy 里的对应技巧**：

```
log(正确类别的概率) = logit[正确类别] − logsumexp(logits)

logsumexp(x) = max(x) + log(Σ exp(x − max(x)))
```

---

## 五、★ 最优雅的结果

```
∂loss/∂logits = softmax(logits) − one_hot(labels)
```

**就是"预测减真实"。** 没有指数、没有除法。

**含义**：正确类别的分数**往上推**，其他类别**往下压**。

这个式子在 Day 4（线性回归）和 Day 6（softmax 分类器）会反复用到。

## 六、检验与思考

### 1. 为什么分类用交叉熵，而不是「直接比较类别编号的差值」？

> 交叉熵是基于概率的一个信息，可以用来分类。

**补充 —— 关键在「编号是可以随便排的」：**

```
方案一： 猫=0  狗=1  飞机=2
方案二： 猫=2  狗=0  飞机=1
```

两种编号下，"猫和狗的距离"从 1 变成 2——**但分类任务本身一个字都没变**。
所以"编号差值"凭空假设了类别之间有距离，而这个距离纯粹是排列顺序的产物。

交叉熵作用于**概率分布**，只问"模型给正确答案的概率有多高"，不关心类别怎么编号。

> 另外：交叉熵**可导**，编号差值不可导（离散的）。loss 必须可导才能求梯度，这是硬约束。

### 2. `softmax(logits)` 里 logits 需要先变成概率吗？为什么？

> softmax 就是为了变成概率。

**补充 —— 这题的问法本身有点绕，等价于：**

> **没人会给你概率。** 模型输出天然就是 logits（原始分数），softmax 就是专门把 logits
> 变成概率的那一步。所以"logits 要不要先变成概率"不成立——它俩是"原料"和"成品"。

**实际工程含义（这才是要记的）：**

```python
# ❌ 错误：softmax 算了两次
probs = softmax(logits)
loss = nn.CrossEntropyLoss()(probs, labels)   # 它内部还有一次 softmax

# ✅ 正确：传 logits
loss = nn.CrossEntropyLoss()(logits, labels)
```

### 3. 交叉熵和 KL 散度什么关系？为什么最小化其中一个就够了？

> 在一个确定概率分布下，交叉熵 = 熵 + KL 散度。 ✓

**展开**：

```
CE(p, q) = H(p) + KL(p ‖ q)
              ↑         ↑
        真实分布的熵   两个分布的差异
        （训练时是常数）
```

因为 `H(p)` 是常数，最小化 CE 和最小化 KL 完全等价。

### 4. softmax 减最大值为什么不影响结果？

> 上下消去了。 ✓

**展开**：

```
exp(xᵢ − c)          exp(xᵢ)·exp(−c)        exp(xᵢ)
────────────  =  ────────────────────  =  ────────────
Σ exp(xⱼ − c)      Σ exp(xⱼ)·exp(−c)      Σ exp(xⱼ)
                        ↑
                    exp(−c) 上下约掉了
```

**所以结果和 c 无关。** 减多少都行，减最大值只是为了让数值好看。

### 5. 为什么不先 softmax 再取 log，而是直接用 log-sum-exp？

> 主要是因为浮点数计算精度问题，可能会导致舍去，导致某些小数值无法参与运算。

**补充 —— 具体现象是「下溢成 0」：**

```
logits = [0, -1000]，正确答案是类别 1

先 softmax：概率 = [1.0, 0.0]      ← 0 是下溢的结果，不是真的 0
再取 log：  log(0) = −inf          ← 不是"忽略不计"，是变成无穷大

用 logsumexp 直接算：1000.0        ← 正常
```

> 关键区别：下溢不是"这个数变得很小"，而是**它变成了 0**。
> 而 `log(0)` 不是"很小"，是 **−∞**。整个 loss 就废了。
