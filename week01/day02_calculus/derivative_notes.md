## 核心一句话

> **反向传播 = 链式法则 + 从后往前传。**

每个节点做的事只有一件：

```
        局部导数  ×  上游梯度
        （只看自己）  （从后面传回来的）
```

**关键**：局部导数只跟自己有关，不用管前面后面长什么样。
所以每个算子只需要知道"我的输入变一点，我的输出变多少"，整条链就自动串起来了。

## 概念速览（答验收题前先过一遍）

### derivative（导数）是什么

```
              f(x + h) − f(x)
f'(x) = lim   ─────────────────
        h→0          h
```

**它表示「局部变化率」**——在 x 这一点上，x 变动一点点，f 跟着变多少倍。

**"局部"是关键词**：它只描述**当前这一点附近**的行为，不保证远处也这样。
同一条曲线上，每个点的导数都可以不一样。

### partial derivative（偏导）和 derivative 的区别

| | 什么时候用 |
|---|---|
| **derivative** | 只有一个变量时 |
| **partial derivative** | 多个变量时，**只对其中一个求导，其余都当常数** |

```
f(x, y) = x² + 3xy + y³

∂f/∂x = 2x + 3y        ← 把 y 当常数
∂f/∂y = 3x + 3y²       ← 把 x 当常数
```

符号用 **∂**（圆 d）而不是 d，就是在提醒你：**"还有别的变量，只是它们现在不动"**。

### gradient（梯度）

把所有偏导**打包成一个向量**：

```
∇f = [∂f/∂x, ∂f/∂y, ...]
```

两个性质：

1. 它指向**函数上升最快**的方向
2. 所以下降要往 **−∇f** 走 —— 这就是梯度下降

### upstream gradient 和 local derivative

反向传播里，每个节点只看两样东西：

| 名字 | 是什么 |
|---|---|
| **local derivative**（局部导数） | 这个节点**自己**的导数：输入变一点，输出变多少 |
| **upstream gradient**（上游梯度） | 从后面传回来的、loss 对这个节点**输出**的梯度 |

**节点做的事**：把两者相 **乘**，往前传。

```
往前传的 = local derivative × upstream gradient
```

这两个词来自 Karpathy 的 micrograd，Week 2 会正式用到。

### 两个激活函数（记牢）

```
ReLU:     f(x) = max(0, x)          f'(x) = 1 (x>0)  /  0 (x<0)
Sigmoid:  σ(x) = 1/(1 + e^(−x))     σ'(x) = σ(x)·(1 − σ(x))
```

> Sigmoid 的导数**最大只有 0.25**（在 x=0 处）。这就是梯度消失的原因之一——
> 每经过一层 sigmoid，梯度至少打 4 折。

### A. 概念（能不能讲清楚）

> **我的答案**（2026-09-16 完成，5/5）

**1. derivative 是什么？为什么说它表示「局部变化率」？**

> 导数是**局部切线斜率**，所以是局部变化率。

**2. partial derivative 和 derivative 有什么区别？**

> 偏导是对某个变量求导。

*（补充：关键是「**其余变量当常数**」——这是偏导的定义特征）*

**3. gradient 是什么？**

> 梯度指的是函数对各个变量的偏导组成的向量。

*（补充：它指向**上升最快**的方向，所以下降要走 −梯度）*

**4. chain rule 为什么能把 loss 的梯度一路传到参数？**

> 因为 loss 的梯度可以通过链式法则反向向前计算，
> 这样就能知道具体的参数对结果的影响。

**5. 什么是 upstream gradient 和 local derivative？**

> 上游梯度就是对于某个部分，**loss 对输出的敏感程度**；
> 局部导数就是**输出对输入的敏感**。
> 根据链式法则相乘，得到 **loss 对输入的敏感**，可以再次向前传播。
