# NumPy 语义速览

> **前提：你懂线性代数。** 这份文档不讲数学，只讲「NumPy 这个库怎么表达那些数学」。
> 线代课上不教这些，所以「学过线代」和「看不懂 shape_drills」完全不矛盾。

---

## 0. 先建立正确的心智模型

一个 `ndarray` 是三个东西：

```
ndarray = 一块连续内存  +  一个 shape（怎么解读这块内存）  +  一个 dtype
```

**关键领悟：`shape` 是「解读方式」，不是数据本身。**

所以 `reshape` / `transpose` / 切片 都是在**换一种解读方式**，有时根本不复制内存（叫"视图"）。

### 数学矩阵 vs NumPy 数组的区别

| | 数学 | NumPy |
|---|---|---|
| 维度 | 矩阵是 2-D 对象，向量是特殊的矩阵 | **n 维都行**，1-D 数组有自己独立的行为 |
| 类型 | 只有矩阵 | 标量/1-D/2-D/3-D… 行为各不相同 |
| 乘法 | 只有一种矩阵乘法 | `A @ B`（矩阵乘）和 `A * B`（逐元素乘）是**两个东西** |

**最后一行是最大的坑**：数学里你不区分，NumPy 里必须区分。

```python
A * B    # 逐元素相乘（Hadamard 积），要求 shape 能广播
A @ B    # 矩阵乘法，要求内维相消
```

## 1. `axis=k` 的语义

### 一句话：**`axis=k` 的意思是"第 k 维要消失"。**

```
x.shape = (4, 3)
            ↑  ↑
         axis=0  axis=1

x.sum(axis=0)  →  沿着 axis=0 方向压扁  →  (3,)    ← 第 0 维没了
x.sum(axis=1)  →  沿着 axis=1 方向压扁  →  (4,)    ← 第 1 维没了
x.sum()        →  全部压扁             →  ()      ← 标量
```

**助记：`axis=k` = "这一维要没"**

### 放到深度学习的语义里

`x` 是 `(B, D)` = `(batch, feature)`：

| 写法 | 含义 | 结果 |
|---|---|---|
| `x.sum(axis=0)` | **跨样本**相加 | `(D,)` |
| `x.sum(axis=1)` | 每个样本**内部跨特征**相加 | `(B,)` |

新手最容易混的就是这个。**永远先问自己："我要在哪个方向上归约？"**

### axis 可以传元组

```python
img.shape = (4, 2, 32, 32)          # (B, C, H, W)
img.mean(axis=(2, 3)).shape         # 一次压掉两维 → (4, 2)
```

## 2. Broadcasting（广播）

### ⚠️ 这**不是数学概念**，是 NumPy 的工程发明

数学里没有"广播"。它的目的是：**让不同 shape 的数组能做逐元素运算，而且不真的复制数据**（省内存、省时间）。

所以你不能从线代推出它——只能记住规则。

### 三条规则

```
从最右边开始对齐，逐维比较：

  ① 相等          → 通过
  ② 其中一个是 1   → 拉伸到另一个的长度
  ③ 都不等且都不是 1 → 报错 ValueError
```

缺的维度**当作 1** 处理。

### 判定流程（照着走）

**例 1：能广播**

```
A.shape = (4, 3)
B.shape = (3,)

第①步 从最右对齐：
        A:  4   3
        B:      3

第②步 逐维比较（从右往左）：
        最右维:  3 vs 3   → 相等 ✓
        第 0 维: 4 vs 缺失 → 缺失当作 1，拉伸成 4 ✓

结果: (4, 3)
```

**例 2：报错**

```
A.shape = (4, 3)
B.shape = (4,)

对齐：
        A:  4   3
        B:      4

最右维:  3 vs 4  →  不等，且都不是 1  →  ❌ ValueError
```

### 为什么这是 DL 里最常踩的坑

看例 2：`(4,)` 在你的**语义**里像是 batch 维，但 NumPy 从**右边**对齐，把它当成了最后一维。

> **语义和机制不一致** —— 这就是 `keepdims` 存在的全部理由（见 §5）。

### 手算模板

以后遇到广播，在纸上这样写：

```
   A:  _  4  3
   B:  _  _  3
      ─────────
       ✓  ✓        →  (4, 3)
```

## 3. 1-D 数组在 `@` 里的提升规则 ★

数学上你知道矩阵乘法 `(m,k) @ (k,n) → (m,n)`。但 NumPy 允许 1-D 参与运算，规则是：

| 1-D 在 | 被当成 | 结果 |
|---|---|---|
| **右边** | 列向量 `(k, 1)` | 算完**去掉后面**那个 1 |
| **左边** | 行向量 `(1, k)` | 算完**去掉前面**那个 1 |

### ⚠️ 注意这是不对称的

设 `b.shape = (5,)`，`W.shape = (3, 5)`，于是 `W.T.shape = (5, 3)`：

```
b @ W.T   →  b 在左，当行向量 (1,5)
             (1,5) @ (5,3) → (1,3) → 去掉前导 1 → (3,)   ✓

W.T @ b   →  b 在右，当列向量 (5,1)
             (5,3) @ (5,1) → 内维 3 vs 5 → ❌ 报错
```

**同样一个 b，站左边能跑，站右边就炸。** 你没法从数学判断 NumPy 会怎么处理——只能记规则。

### 工程结论

> **深度学习的代码里永远显式写 `(B, D)`，不要依赖 1-D 自动推断。**

因为读代码的人（包括三个月后的你）根本看不出哪里会炸。

## 4. `.T` / `reshape` / `transpose`

### `.T` —— 分情况，别乱用

| 维度 | 行为 |
|---|---|
| 2-D | 正常转置 ✓ |
| **1-D** | **什么都不做**！`(3,).T` 还是 `(3,)` ❌ |
| n-D（≥3） | 反转**所有**轴 → 通常不是你想要的 ❌ |

3-D 以上请用 `transpose(轴序)` 明确指定。

### `reshape` vs `transpose` —— 这是最容易写错的地方

```python
x = np.arange(6).reshape(2, 3)
# x = [[0, 1, 2],
#      [3, 4, 5]]
```

**`x.reshape(3, 2)`** —— 按内存顺序重新切分：

```
内存里的顺序:  0 1 2 3 4 5

切成 (3,2):   [[0, 1],
               [2, 3],
               [4, 5]]
```

**`x.T`** —— 真的转置：

```
[[0, 3],
 [1, 4],
 [2, 5]]
```

**结果完全不同！** `reshape` 只是换了个"切法"，`transpose` 才是换轴。

### 3-D 时更明显

```python
seq.shape = (4, 6, 3)        # (B, T, D)

seq.reshape(6, 4, 3)         # shape 对了，但数据是乱揉的
seq.transpose(1, 0, 2)       # shape 一样，数据才是真的换了轴
```

两者 shape 都是 `(6,4,3)`，但**内容完全不同**。这是 Attention 里最容易埋 bug 的地方。

### 判断口诀

> **换维度顺序 → `transpose`**
> **合并 / 拆开维度 → `reshape`**

### 补充：视图 vs 拷贝

两者都尽量返回**视图**（不复制内存）。但 `transpose` 之后内存不连续，此时再 `reshape` 可能触发一次真实拷贝。平时不用管，但看到 `.copy()` 或性能问题时要知道这个背景。

## 5. `keepdims` —— 为什么必须有它

### 问题

`sum / mean / max / norm(..., axis=k)` 默认把第 k 维**删掉**。

```
x.shape = (4, 3)

m = x.mean(axis=1)          # (4,)   ← 第 1 维被删了
x - m                       # ❌ (4,3) - (4,) → 从右对齐 3 vs 4 → 报错
```

### 解法

```python
m = x.mean(axis=1, keepdims=True)    # (4, 1)  ← 第 1 维变成 1，而不是消失
x - m                                # ✓ (4,3) - (4,1) → 广播成 (4,3)
```

### 为什么这样就好了

回到 §2 的广播规则：

- `(4,)` 被从右对齐 → 当成最后一维是 4 → 和 `x` 的 3 冲突 ❌
- `(4,1)` 最后一维是 **1** → 可以拉伸成 3 → 通过 ✓

> **`1` 可以被广播，消失的维度不能。**

### 口诀

> **归约之后还要参与运算 → 加 `keepdims=True`**

典型场景：归一化（减均值 / 除标准差）、LayerNorm、BatchNorm、梯度裁剪。

## 6. `np.linalg.norm` 的 axis

L2 范数 = √(各元素平方和)，也就是"长度"。

```python
x.shape = (4, 3)

np.linalg.norm(x)                       # 不给 axis → 整个数组拉平求 → 标量 ()
np.linalg.norm(x, axis=1)               # 沿第 1 维求 → 每行一个长度 → (4,)
np.linalg.norm(x, axis=1, keepdims=True)# (4, 1)
```

规则和 §1 一致：**给了 axis，那一维就消失**。所以想要广播就得配 `keepdims=True`：

```python
x / np.linalg.norm(x, axis=1, keepdims=True)   # ✓ 每行 L2 归一化 → (4,3)
x / np.linalg.norm(x, axis=1)                  # ❌ (4,3)/(4,) → 报错
```

就是 §5 那个坑，换个函数再来一次。

## 7. 速查表：数学 → NumPy

| 数学 | NumPy | ⚠️ 注意 |
|---|---|---|
| 矩阵 (m,n) | `np.zeros((m,n))` | |
| 转置 Aᵀ | `A.T` | **1-D 无效** |
| 矩阵乘法 AB | `A @ B` | 内维相消 |
| **逐元素乘** | `A * B` | **不是矩阵乘法！** |
| 点积 a·b | `a @ b` | 1-D 时返回标量 |
| 求和 Σ | `.sum(axis=k)` | 该轴消失 |
| 范数 ‖x‖ | `np.linalg.norm(x, axis=k)` | 该轴消失 |

**最容易出事的两行：**

1. `*` 和 `@` 是两回事（数学里不区分，NumPy 里区分）
2. `.T` 对 1-D 无效
